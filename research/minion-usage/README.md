# Usage and subscription observability

A Hub user wants to understand which coding sessions, credentials and subscriptions consume capacity across their registered Workers. A Hub administrator sees telemetry across registered Workers. Each person organizes that information privately, including administrators. The requested destination is a separate Usage menu with an interface usable by web, MCP and, later, mobile clients.

## Native sources and translations

| Source | Supported evidence and handling |
|---|---|
| [Claude Code status line](https://code.claude.com/docs/en/statusline) | The native status payload can report the model, duration, estimated cost, token counters and subscription windows. Five-hour and seven-day windows have independently optional used percentages and reset timestamps in seconds. A gateway spend limit is a different unit and auth mode. Subscribe to an explicitly installed metadata projection, preserving the owner's existing status line. A cold session may have no window yet. |
| [Codex app-server](https://developers.openai.com/codex/app-server/) | Read account information with refresh disabled. A separate stdio client can request account/rateLimits/read for a ChatGPT account without starting a thread. Parse the per-limit map when present and use the legacy summary only as fallback. Preserve scope, windowDurationMins, usedPercent and resetsAt. Thread usage notifications are cumulative or last-turn, and need an explicit choice for accounting. |
| [Gemini CLI quotas](https://geminicli.com/docs/resources/quota-and-pricing/) and [telemetry](https://geminicli.com/docs/cli/telemetry/) | The native stats view reports model usage and applicable limits. An isolated, user-designated collector may expose stats. Native token metrics carry input, output, thought, tool and cache categories. Strip prompt, trace, email, tool name/arguments and output fields at the source. API and Vertex usage stay separate from Google subscription windows. |
| [DeepSeek usage](https://api-docs.deepseek.com/api/create-completion/) | DeepSeek is a model/API provider. Compatible harnesses report DeepSeek as the provider when configuration or response metadata supports it. Input already includes cache hits and misses. Preserve the cache subset without counting it twice. An API balance is money and cannot stand in for a subscription window. |
| [OpenTelemetry GenAI conventions](https://opentelemetry.io/docs/specs/semconv/gen-ai/) | Map provider, requested/response model, operation duration and input/output/cache token counts onto a narrow project schema. Record the adapter version. Omit optional prompt, tool and output payloads and high-cardinality raw credentials. |
| [SQLite WAL](https://sqlite.org/wal.html), [OpenAPI 3.1](https://spec.openapis.org/oas/v3.1.1.html), [MCP tools](https://modelcontextprotocol.io/specification/2025-06-18/server/tools) | Reuse the Hub WAL database and its backup/migration mechanism. One typed projection powers the HTTP envelope, JSON Schema and MCP structured output. Use bounded pages and identical authorization at every entry point. |

No cited provider promises a portable safe polling interval. Five minutes is the requested operational ceiling. Obey a longer provider cooldown and use passive native observations where available. Use a dedicated collector only where a supported non-generating path exists.

## Identity, access and accounting

* A connected, approved Worker is the authoritative source of its Worker ID. Bind each sample to its owner at collection time. Remove private telemetry when ownership changes, so reassignment cannot disclose history. Derive the viewing identity server-side. Deny impersonated access to another person's bucket definitions. Restrict scoped API keys to their authorized data.
* Register Workers with an explicit, visible description of metadata collection that also covers unshared sessions. The usage transport has typed, bounded fields. It never transmits the console buffer, commands, prompts, task descriptions, tool arguments, log lines, keys or login files. Start/stop/completion are event names. Folder and session name are disclosed metadata and can themselves be sensitive. Debug is bounded to counters, reason codes, time and collector health.
* Use native stable account IDs where available. An unknown account stays unassigned, including same-vendor accounts that cannot be distinguished. API identity includes the canonical endpoint and a cryptographic key fingerprint derived locally. Display an owner-supplied label or a masked prefix plus a fingerprint suffix. Suppress prefixes for short credentials; never transmit complete credentials or endpoints containing credentials/query fragments.
* Deduplicate per account and resource scope, using one latest observed window. Represent unknown separately from zero. If only percentages exist, report the mean for comparable windows and count known, stale and unknown accounts. It describes an unweighted account mean. A capacity-weighted number requires compatible known limits/units. Distinct periods, model scopes and units keep separate summaries. When known reset and length yield a valid start, compare used percentage to elapsed percentage. A tolerance around elapsed time prevents status flapping. A limitless/rolling observation with no defined comparable interval has unknown pace.
* At a five-second cadence, 20–50 sessions yield 4–10 candidate updates/s, 345,600–864,000 candidates/day. Coalesce unchanged cumulative snapshots, retain latest state, store actual lifecycle changes and hourly last-counter/delta rollups in indexed SQLite tables. Keep raw changes short-lived, trim in bounded batches, retain longer rollups, benchmark bursts and short reader/writer contention. A vector index offers no benefit for typed time series.
* The local CPA designs 08-quota-source-of-truth and 09-quota-history separate scheduling from display and preserve upstream observation times. Adopt those ideas; user-selected Minion collectors must report origin and observation time even when Hub reception is delayed. The CPA service and its credentials are outside this feature.
