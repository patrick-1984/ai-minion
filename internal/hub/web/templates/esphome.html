Install Minion on an ESP32

Connect an ESP32, ESP32-S3, ESP32-C3 or ESP32-C6 with at least 4 MB of flash over USB. Use a computer with Python 3 and uv, pipx or esptool 4.x. Replace /dev/ttyUSB0 with the board’s serial port.

Installing the Minion firmware replaces the application on the board. The script asks before overwriting an existing flash layout. Insert --update after the port on a board already running Minion to update the application and keep its identity and settings.

  1. Open the board’s serial console at 115200 baud and run wifi set <ssid>. Enter the Wi-Fi password at the hidden prompt.
  2. Run config set hub <Hub URL> and reboot.
  3. Create an invitation key. Run enroll on the board and paste the key at the hidden prompt.
  4. Run status on the board. Compare its Hub fingerprint with the fingerprint shown in this Hub and approve the matching Worker in Workers.

Keep ESPHome and bridge its logs

Use a second ESP32 running Minion and connect its UART RX to the ESPHome device’s hardware UART TX. Share ground and use matching logic voltage and baud. Leave Minion’s TX wire disconnected for a receive-only connection.

In ESPHome, direct logger to that hardware UART. In the Minion board’s local console, set allowed GPIOs with config set gpio_allow <pins>, run uart set <baud> <tx-pin> <rx-pin> and reboot. The TX pin is configured on the Minion board and stays unwired. 

logger:
  hardware_uart: UART0
  baud_rate: 115200

Use the UART that your ESPHome board routes to the chosen TX pin.

Open a device session

Open Sessions and choose the Worker. Open console to run firmware commands, log to read the Minion board’s logs, or uart to read the bridged device’s logs. MCP and API clients can find these sessions with sessions_list and read them with session_snapshot.
