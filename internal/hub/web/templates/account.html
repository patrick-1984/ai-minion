Sessions

A new session is hidden when you could not see or join it from your own terminal: on Windows a ConPTY session inside the Worker (psmux is not installed, or the Worker runs as a service), on Linux and macOS a tmux server that is not your default one. Visible sessions show in tmux ls or psmux ls and you can attach to them.

Hidden describes what you can see from your own terminal. The Hub can allow or block creation of hidden sessions for everyone, or let each user decide.
