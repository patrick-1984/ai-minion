{{end}} {{define "passphrase-policy"}}

Passphrase rules. At least 14 characters (Unicode code points, not bytes) and at most 1024 bytes in UTF-8.

  • Stronger is better: a sentence of four or more unrelated words, or a long random string from a password manager, is recommended. It cannot be recovered if you lose it.
  • Use one that you use nowhere else, and not your login password (the Hub refuses that).
  • You may type any Unicode characters, including spaces and letters with accents. Characters are counted as code points, so one emoji counts as one, but every character takes 1 to 4 bytes of the 1024. Type it the same way every time: the Hub does not normalize it, so a different keyboard layout or input method can produce a different passphrase.
